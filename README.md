# HopeHub — NGO / Social Impact Website

A responsive front-end website concept built with **HTML, CSS and vanilla JavaScript** for a beginner web-development challenge.

## Project files

- `index.html` — page structure and content
- `style.css` — responsive layout, colors, typography and visual design
- `script.js` — mobile navigation, scroll reveal, animated counters and demo form interaction

## Run it on a phone

1. Download and unzip `HopeHub-Website.zip`.
2. Open the folder in Replit, StackBlitz or another HTML editor.
3. Make sure all three files are in the same project folder.
4. Open `index.html` or press **Run** / **Preview**.
5. Check the page at mobile and desktop widths.

You can also preview it locally by opening `index.html` in a browser.

## Features

- Responsive navigation menu
- Hero section and mission introduction
- Three program cards
- Animated illustrative impact counters
- Volunteer interest form with front-end validation and confirmation
- Scroll reveal effects
- Keyboard skip link and reduced-motion support

## Important project notes

- **HopeHub is a fictional student project concept**, not a real registered NGO.
- The impact numbers are illustrative sample figures, not verified results.
- The volunteer form is a front-end demonstration only. It does not send, save or transmit submissions. A real deployment would need a secure backend or form service and a privacy notice.
- The photos and Google Fonts are loaded from external services, so an internet connection is needed to display them. The core page layout and interactions are local.
